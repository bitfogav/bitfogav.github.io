BFG Bunker System.

A modular bunker framework for DayZ, developed around configurable access control, custom triggers, door management, loot and server-side administration. Built to extend underground gameplay while keeping important decisions on the server.

ENFORCE SCRIPTDAYZ MODDINGCLIENT + SERVERJSON CONFIGURATION

What it does.

The system is split into focused components, allowing bunker behaviour to be configured and managed without treating every entrance, door and trigger as the same object.

01 / BAC

Keycard access

Configurable card classes, panel mappings and access checks for bunker entrances.

02 / STS

Smart triggers

Box-based trigger volumes, including rotated shapes and teleport-related behaviour.

03 / DOORS

Door control

Dedicated door configuration, control logic, admin locking and helper tools.

04 / CONTROL

Bunker lifecycle

Tracks bunker state, participants, resets and reconnect-related behaviour.

05 / LOOT

Loot management

Configurable loot handling integrated with the bunker runtime.

06 / TOOLS

Admin and diagnostics

Placement helpers, debug utilities, configuration management and server logging.

Inside the code.

A few small excerpts from the project source. These show implementation techniques without publishing the full bunker logic, private configuration or complete mod.

Box trigger centre

STS_ZoneMath.c

Converts a ground-level box position into the centre used for trigger calculations.

// get centered box position from ground/base position
static vector GetBoxCenterFromBase(vector basePos, vector size)
{
    vector center = basePos;
    center[1] = center[1] + (size[1] * 0.5);
    return center;
}

Axis-aligned trigger check

STS_ZoneMath.c

Checks whether a world position falls inside a configured box volume.

// axis-aligned box check
static bool IsInsideBox(vector point, vector basePos, vector size)
{
    vector center = GetBoxCenterFromBase(basePos, size);
    vector delta = point - center;

    vector half = size * 0.5;

    return (Math.AbsFloat(delta[0]) <= half[0] && Math.AbsFloat(delta[1]) <= half[1] && Math.AbsFloat(delta[2]) <= half[2]);
}

Server logging levels

BFG_BunkerLogger.c

Routes diagnostic messages through the bunker logger according to the configured logging level.

static void Warning(string module, string message)
{
    if (s_LogLevel >= 2)
    {
        Log(module, message, "WARNING");
        Print("[BFG_Bunker] [" + module + "] WARNING: " + message);
    }
}
