Get Player Steam64 ID

PLAYER

Read the Steam64 ID from a connected player's identity.

PlayerIdentity identity = player.GetIdentity();

if (identity)
{
    string steamID = identity.GetPlainId();
    Print("Steam64 ID: " + steamID);
}

Get Shoulder Attachment

INVENTORY

Read the item currently attached to the player’s shoulder slot.

{

    if (item)
        Print("Shoulder item: " + item.GetType());

Check Radius

UTILITY

Check whether a position is inside a circular area using horizontal distance.

vector center = "5000 0 5000";
vector position = player.GetPosition();
float radius = 100.0;

float dx = position[0] - center[0];
float dz = position[2] - center[2];

if ((dx * dx + dz * dz) <= radius * radius)
    Print("Player is inside the zone");

Delayed Callback

SERVER

Run a function once after a two-second delay.

void StartDelayedTask()
{
    GetGame().GetCallQueue(CALL_CATEGORY_SYSTEM).CallLater(DoDelayedTask, 2000, false);
}

void DoDelayedTask()
{
    Print("Two seconds have passed");
}
